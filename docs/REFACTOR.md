## 调整内容

| 原有耦合 | 调整后 |
| --- | --- |
| 后端入口同时创建数据库、注册路由、处理错误 | 入口仅创建应用，生命周期和 HTTP 职责分别维护 |
| 路由依赖全局存储与流水线 | 使用当前应用的依赖，支持多个独立实例与测试替换 |
| 路由调用流水线私有摘要方法，并自行计算统计 | 使用公开 `get_summary()`，统一通过 `build_task_summary()` 组装 |
| 摘要通过动态导入读取日期和 JSON | 使用明确的模块导入，便于静态分析 |
| MiMo 引用 Tavily 的私有网络工具 | 两者依赖公共网络异常分类模块 |
| App.vue 同时管理页面与全部任务状态 | 将任务、筛选和服务状态拆为三个组合函数 |
| 部分测试导入入口后可能连接真实数据库 | 临时数据库、默认离线模式和显式依赖注入 |

数据库和供应商初始化由导入时移到应用启动阶段，初始化失败会在启动时报告；资源在退出或启动失败时关闭。前端轮询间隔仍为 1.5 秒，总预算仍为 3 分钟，筛选、重试与导出行为保持原样。
