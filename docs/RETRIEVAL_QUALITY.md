# 断句与检索质量设计

本轮优化针对可核验声明的边界、检索词重复与失焦、网页摘录及候选排序。继续使用确定性规则，不增加模型调用或分词服务，API 字段保持兼容。

## 原文与规范化文本

`source_text` 保留原始片段，`char_start/char_end` 仍为 JavaScript UTF-16 半开区间。全角字符、列表编号和 Markdown 的清理由 `normalized_claim` 承担，不能先修改原文再计算位置。

断句识别中英文句末、段落和列表，并保护小数、版本、网址、常见英文缩写以及括号内的内容。连续句末标点和右引号随前一句保留；中文逗号不作为一般分隔符，避免将适用条件、否定与比较关系拆离主句。候选计数与实际抽取使用同一规则，显式 Markdown 标题和纯格式行不占声明名额。

规范化保留数值、单位、时间、否定和范围。声明抽取层现在允许从原文补回可确定的共同主语和时间；不使用外部知识补充主体，也不将指代不明的代词替换为猜测的实体。网页证据的句子边界仍使用原有保守规则。

### 并列事实拆分（2026-09-20）

`claim_segmentation.py` 在声明层拆分可识别的并列谓语，并将共享前缀用于 `normalized_claim`，原文片段和 UTF-16 位置保持不变。支持句首时间、共享主语、明确主体切换、无逗号的并列动作，并保护标题书名、括号、否定、条件、因果与推测关系。模型返回结构化 `source/context`，程序校验 source 完整覆盖、context 是同句已有前缀；本地能确定的边界还会复核主语与范围，裁掉模型误复制的前一个事实。模型失败、过粗整句与离线模式均有本地拆分支持。

截图复合句“签署条约、割让领土、宣布官方语言”作为回归样例，应抽取三条独立声明并保留共同主语与时间。测试见 `backend/tests/test_atomic_claims.py`，另覆盖条件和否定保留、上下文伪造拒绝、UTF-16 定位、上限计数、失败回退与进入检索的完整声明。规则只覆盖明确结构，不代表任意复合句都能正确拆分。

### 断句分层与上下文继承

1. `candidate_spans` 只确定句子边界，保留小数、网址、括号和书名。
2. `_clause_boundaries` 寻找顶层逗号及并列动作连接词；每段必须有可识别的谓语，否则保留整句。不能把时间短语、宾语列表拆成事实。
3. `SharedScope` 分开记录时间、主语和谓语前的地点等限定。省略主语时继承当前作用域；明确更换主语时清除旧主语和地点；明确更换年份时覆盖旧年份。简单地点变化保留主语并更新地点；时间与地点混合且不能可靠区分时保留整句。
4. `normalize_atomic_claim` 仅清理派生声明的并列连接词和末尾逗号，原文、标点和 UTF-16 区间保持不变。不把“并州大学”等名称的首字当连接词删除。
5. 模型切分复用相同规则进行细化和验证。对于本地可确认的边界，允许继承同句最近出现的新主语；上下文仍必须是此前的连续原文。不能引用其他句子、遗漏条件或重用旧主语。规则不能确认的结构继续采用句首前缀限制，校验失败回退本地规则。

截图应得到三个动作：“三国时期，诸葛亮与凯撒大帝在华盛顿签署《马关条约》”“三国时期，诸葛亮与凯撒大帝在华盛顿割让澳大利亚给日本”“三国时期，诸葛亮与凯撒大帝在华盛顿宣布日语成为联合国唯一官方语言”。这里保留原文断言，不在拆分阶段判断真伪或纠正事实。时间、人物、地点不另拆成脱离动作的事实；“宣布……”的内容也不改成无归属的事实断言。

否定、条件、因果、推测、引述及括号内的限制继续约束整句。书名中的“未来”等词不再被误当成句子的推测标志。此规则仍是有限语法解析，不保证复杂人名、介词短语和跨句指代的语义分析。

## 查询计划

每条声明最多三个查询，每个查询最多 160 字符。实体、动作、时间、数值和条件先规范化再去重，已经出现在声明中的结构字段不重复拼入。

精确查询保留原声明的关键限制；可识别的属性或数值陈述还生成不包含待核验答案的中性查询，例如查询某机构在某年的研发投入时，不把声明中的金额作为唯一检索条件。数值冲突的页面仍可能是有效反证。无法可靠抽取结构时保留清洗后的文本，不一律追加“分类”，也不全局强制政府或教育域名过滤。

长查询优先在分句或空白边界压缩到长度上限；没有可用边界的超长片段会截断，因此长标识符仍需要人工核对。原始完整声明仍留给判断阶段。最终执行的查询保存在 `Claim.queries`，可在现有页面的“检索词”中查看。

例如“华为在2024年的研发投入为1797亿元。”保留精确查询，同时生成“华为 研发投入 在2024年”；“在标准大气压下，纯水的沸点不是90摄氏度。”的精确查询保留否定和数值，中性查询为“纯水的沸点 在标准大气压下”。这些是查询生成示例，不代表对声明的事实判断。

## 网页与摘录

供应商返回的文本继续经过现有安全处理，不新增任意 URL 抓取。摘录必须是清洗后正文中的一个连续片段，最多 1000 字符，不拼接或改写原文。

选择摘录时比较实体与主题词的覆盖，降低导航、登录及其他模板文本的影响。长单段正文也需要搜索靠后的内容，不能只截取前 1000 字符。

网页排序依据所保存正文片段与声明的词项覆盖，内容相关性优先于域名权威性；摘要、社交来源和正文仍区分处理。同一 URL 多次返回时优先保留正文，再比较文本长度，避免先到的摘要覆盖后到的正文。相同站点或相同内容继续聚类，优先保留独立来源。

## 来源与相关性筛选（2026-09-20）

检索增加以下门槛，未达到门槛时允许返回空证据，不用噪声补满五条：

- `source_policy.py` 统一检索和判断阶段的来源类型。社区、论坛、个人投稿不进入新证据；音乐、词典页面仅在对应作品或语言主题下作为线索保留，不能独立参与事实定论。历史证据重新判断时也受相同来源类型限制。
- 域名采用完整主机名及子域边界匹配，不根据 URL 路径、标题或伪装域名授予权威分。政府、高校、科研科普平台和新闻媒体使用分级先验；百科和未知网站保持较低先验。域名分数不代表网页内容已核实。
- 正文主题词覆盖至少 30%，不能仅凭标题或相同数字入选。数字不作为相关性门槛，保留数值冲突的潜在反证。已识别的部分常见主语检查正文中的名称或别名，避免把光速当成声速；其他复杂主体仍交由语义判断。
- 导航模板、验证拦截页面及标题明显属于同名歌曲、小说、游戏的跨主题结果会被过滤。摘录依然是原文连续片段。
- 候选先过相关性门槛，再按正文完整性、主题覆盖与来源先验排序；独立证据组及组内页面均按最终排名返回，避免界面恢复到旧顺序。

查询继续受每条最多三次、每次五条、每个查询 160 字符的上限约束。精确查询保留原声明，中性查询把可识别的方向和速度断言改为待查属性，例如“太阳从西方升起”补充查“太阳升起方向”。至少有三个主题词且长度达到六字符时，预留一个查询补充官方原始资料；识别到自然科学主题时使用科研、高校、科普域名定向查询，同时保留普通查询。原有条件字段中的方向或最快等答案也会在中性查询中清理。

查询不会植入预设的正确答案，不增加模型调用，不改变 Tavily 请求深度。`Claim.queries` 记录实际尝试的查询；鉴权、权限、配额等永久错误停止继续请求，如果此前已有结果则保留可用候选。普通单次查询失败仍可继续其他查询。

检索相关性只用于选取候选，不是事实真假的判断分数。支持、反驳与证据不足仍交给既有判断和引用校验流程。

## 验证与边界

从 `backend` 目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pytest tests/test_language_acceptance.py -q
```

独立验收集覆盖英文断句、数值和链接保护、UTF-16 原文定位、格式清洗、有效声明计数、查询去重与限长、长正文摘录、网页相关性排序、数值反证保留以及摘要到正文的升级。样例网页均为本地测试夹具，不代表实际联网检索结果。

2026-09-19 本轮验证：后端 148 项测试通过（含 31 个独立验收样例及 4 个新增边界测试），前端 12 项测试、类型检查与生产构建通过。原有后端基线为 113 项测试。另用约 96 万字符、含 2 万个链接的合成页面检查摘录，成功定位末尾相关事实；该性能探针不代表真实网络延迟。

规则无法完整处理所有缩写、复杂嵌套引用、实体别名、跨句指代或语义等价表达。应使用独立人工标注样本继续评估，不能用单元测试通过率宣称真实搜索准确率。更新后提交新任务才会重新断句和生成查询；历史任务保留原结果，声明重试仅重新检索与判断。

来源策略的回归测试位于 `backend/tests/test_source_filtering.py`，模拟截图中的声速、日出、自转及同名娱乐内容，并覆盖伪装域名、数字反证、摘要、来源排序、空结果、失败隔离和调用预算。它们不调用真实 API，不代表已测得线上检索准确率。规则可能漏掉跨语言、别名或语义改写的有效页面；此时保留“证据不足”，后续可用人工标注集调整阈值和来源分类。

## 2026-10-05 检索优化

Tavily 默认 `advanced`，每个来源最多返回三个相关片段，并继续请求原始文本；`TAVILY_SEARCH_DEPTH=basic` 可以恢复基础模式。深度模式每次消耗 2 credits，基础模式 1 credit，参数及费用见 [官方说明](https://help.tavily.com/articles/6938147944-basic-vs-advanced-search-what-s-the-difference)。每条声明的三次查询及每次五个候选的上限不变。

分类断言增加不带预设类别的查询，例如“鲸鱼是鱼类”对应“鲸鱼 分类 定义”；一般“研究显示”等开场语不再占用中立查询。复合声明从同一页面分别保存最多三个连续原文片段，并明确标记片段间的省略；每个片段最多 1000 字，逐项引用仍须存在于保存文本中。筛选时优先保留直接描述目标属性的材料，并在同站不同页中优先保证不同事实的覆盖。

IPCC、WMO、IMF、世界银行、OECD 和 UNESCO 的官方域名纳入机构来源先验，域名边界校验保持不变，来源身份本身不能代替事实比对。

科学来源查询中的 `site:` 组合会转换为 Tavily 原生 `include_domains`，并纳入中科院 `cas.cn`。正文完整性作为排序中的一项，与相关性、来源先验共同考虑；前置条件后的主体也参与相关性筛选。具体接口字段见 [Tavily 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
