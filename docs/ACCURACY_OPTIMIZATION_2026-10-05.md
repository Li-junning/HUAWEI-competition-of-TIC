# 搜索与正误判定优化记录

本次优化让能核验的事实获得明确结论，重点修复检索相关性、条件比对及跨网页覆盖；保留不同主体、不同指标、时间冲突、缺失事实和虚构引用的拦截。

## 检索调整

- Tavily 默认深度搜索，最多三个相关片段；保留原声明，同时使用不带预设答案的查询。例如“鲸鱼是鱼类”增加“鲸鱼 分类 定义”。
- 科学事实的机构来源查询使用 Tavily 的 `include_domains` 原生过滤，包含中科院 `cas.cn`；原有字符串内的布尔 `site:` 表达式没有可靠落实来源限制。接口字段依据见 [Tavily 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
- 排序综合主题相关性、目标属性、来源先验和正文完整性，有效机构摘要可优于仅有关键词重合的低质量正文。带前置条件的声明先定位主体，减少不同介质或对象混入。
- 复合声明可保留同页中相距很远的事实片段，也优先保留同站不同页中分别描述不同事实的材料。单页最多三个原文片段，每段最多 1000 字，片段间明确标记省略。
- 新增中科院及 IPCC、WMO、IMF、世界银行、OECD、UNESCO 的机构域名先验，保留域名边界检查。

深度模式每次 2 credits，基础模式每次 1 credit，可用 `TAVILY_SEARCH_DEPTH=basic` 恢复基础模式。单条声明仍最多三次查询、每次最多五个候选；费用依据见 [Tavily 官方说明](https://help.tavily.com/articles/6938147944-basic-vs-advanced-search-what-s-the-difference)。

## 判断调整

- 服务端保留通过校验的 `checks`。多个网页可分别证明不同事实，整句支持取最弱一项的覆盖强度；同一证据簇内不重复计算独立性。支持指数使用同一套汇总逻辑。
- 前置的适用条件与其事实合并核对，避免把“在标准大气压下”单独当成事实，同时要求引用覆盖条件及结论。任何一项被充分反驳时，仍可判复合声明错误。
- 来自政府、高校、科研及科普机构的直接摘要，完成逐项引用、主体、属性、范围、答案检查后，可以达到单来源裁决门槛。单一未知来源的摘要和未覆盖的事实仍不能决定结论。
- 支持日期语序变化、标准气压条件的等价表述、同一水沸点指标的“水/纯水/纯净水/蒸馏水”表述、主体与指标之间的条件，以及“100℃作为水的沸点”的倒装定义和 PDF 的 `oC` 温度符号。
- 否定词按引用所在分句检查，保留被截去的否定；相邻指标的否定不再影响当前事实。只允许从紧邻、明确约定同一指标的一般定义中继承条件，不从其他对象或重复且不唯一的语境中借用条件。
- 引用的 NFKC 字符形式或空白差异可定位回唯一的原始连续片段，随后继续做精确原文校验。数字、词语、否定、单位名称的改写和不唯一定位仍拒绝。
- 提示词允许明确语义等价表达，不为未限定年份的稳定事实额外索要观察年份。模型整句为 unknown 时，有效逐项支持/反证仍参与汇总。
- 证据详情新增可展开的逐项核对；不能裁决时说明缺的是事实覆盖、主体/条件匹配还是可靠来源。

- 后端 **487 项测试通过**，含本次 43 项新增回归用例；原有条件与数值冲突测试适配了条件完整绑定协议。
- 前端 **74 项测试通过**，TypeScript 检查与生产构建通过。
- 原有离线合成评估通过，结果位于 `evaluation/results/accuracy-offline-2026-10-05/`。该夹具成绩不是线上准确率。
- 真实 Tavily/MiMo 开发检查及逐项证据位于 `evaluation/results/live-accuracy-smoke.json`。通过 `python evaluation/live_accuracy_smoke.py --live` 复现；不读写用户任务数据库，使用现有 API 密钥并消耗额度。

修改后重启后端，新建任务或重新检索声明。旧任务不会自动重新检索；它们保存的证据和历史标签继续保留。
