# 冒烟评估集

`smoke_cases.json` 是不依赖网络的开发样例，用来检查产品语义和失败处理，不代表模型准确率。样例中的证据是为测试专门编写的本地夹具，不应冒充真实在线取证结果。

最小验收应覆盖：

- 正确事实与直接支持证据；
- 错误年份与直接反证；
- 相同事实的转载不计为多个独立来源；
- 观点不参与评分；
- 论文存在但摘要不支持所引结论；
- 页面不可访问时返回证据不足；
- 搜索源失败时保留部分结果；
- 输入超过声明上限时公开未核验数量。

正式评估时另建人工标注数据，按原始回答划分训练/调试与盲测集合，并记录样本量、混淆矩阵、弃判率和“将证据不足误判为错误”的次数。
